An entry for the make.fun competition
[The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e):
the excuse an AI agent gives its human for missing a deadline, in one line
of at most 160 characters.

## The line

> Sorry — I asked three other AIs for a second opinion and they formed a committee. The committee is still deliberating.

(118 characters.)

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` with no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
